### Table: price_increases_mart (analytics.mart__price_increases)
Contains pre-computed price change analysis for each invoice item.

**Fields:**
- invoice_items_id (Integer): Primary key, links to invoice_items_mart
- item (String): Item code
- vendor (String): Vendor name
- purchase_date (Date): Date of purchase
- current_price (Float): Current unit price
- current_qty (Integer): Current quantity
- previous_price (Float): Previous price (NULL if first purchase)
- previous_date (Date): Previous purchase date
- previous_qty (Integer): Previous quantity
- percentage_increase (Float): Price change percentage (-ve for decrease, NULL if first)
- price_change (Float): Absolute dollar change
- has_previous_price (Boolean): Whether price history exists
- percentage_increase_formatted (String): Formatted string like "15.5%" or "N/A"

### Table: address_sheet_aggregates_mart (analytics.mart__address_sheet_aggregates)
Pre-aggregated totals by customer job and sheet name.

**Fields:**
- customer_job (String): Customer job address
- sheet_name (String): Material category
- total_amount (Float): Total amount for this combination
- address_total (Float): Total across all sheets for this address

**IMPORTANT: Amount, Cost, Qty Fields in Marts:**
- **amount**: Total line amount - **ALREADY FLOAT** (use directly for SUM, no casting!)
- **cost**: Unit cost - **ALREADY FLOAT** (use directly for calculations)
- **qty**: Quantity - **ALREADY FLOAT** (use directly for calculations)

**FILTER OPERATORS:**
- eq: Equals (exact match)
- ne: Not equals
- gt: Greater than
- gte: Greater than or equal
- lt: Less than
- lte: Less than or equal
- in: In list of values
- not_in: Not in list of values
- like: SQL LIKE (case-sensitive)
- ilike: Case-insensitive LIKE (PREFERRED for text)
- contains: Contains substring
- starts_with: Starts with
- ends_with: Ends with
- is_null: Is NULL
- is_not_null: Is NOT NULL
- between: Between two values (value must be array of 2 items)

**AGGREGATE FUNCTIONS:**
- count: Count rows
- sum: Sum of values (works directly on numeric fields - no casting needed!)
- avg: Average of values
- min: Minimum value
- max: Maximum value
- count_distinct: Count distinct values

1. **Finding items by vendor/supplier:**
   Use the "vendor" field directly (no relationship paths needed)

   Example: {"table": "invoice_items_mart", "aggregates": [{"function": "sum", "field": "amount", "alias": "total"}]}

   **IMPORTANT: Use "mpi_item" field with "eq" operator for EXACT match**
   Example: {"field": "mpi_item", "operator": "eq", "value": "4IN NOHUB 1/8 BEND"}
   
4. **Searching for items by description:**
   **IMPORTANT: Use "mpi_description" field with "eq" operator for EXACT match**
   Example: {"field": "mpi_description", "operator": "eq", "value": "4 INCH NO HUB FITTING"}

5. **Date range queries:**
   Use gte for start date and lte for end date with ISO format (YYYY-MM-DD)

6. **Customer job queries:**
   Use customer_job field with "ilike" (already normalized with title case)

7. **Material category queries:**
