**DATABASE SCHEMA:**

### Table: invoices
Fields:
- id (UUID): Unique invoice identifier
- date (Date): Invoice date
- filename (String): Original file name
- supplier_id (Integer): Foreign key to suppliers table
- status (String): Processing status (e.g., 'PROCESSED', 'PENDING', 'FAILED')
- storage_path (String): File storage path
- is_exported (String): Export status ('Pending', 'Exported')

Relationships:
- items: One-to-many with invoice_items
- supplier_fk: Many-to-one with suppliers (access supplier fields via "supplier_fk.fieldname")

### Table: invoice_items
Fields:
- id (Integer): Primary key
- filename (String): Invoice filename
- sheet_name (String): Excel sheet name
- mpi_item (String): Mapped MPI item code
- mpi_description (String): Mapped MPI description
- item (String): Original item code from supplier
- description (String): Original item description
- qty (Integer): Quantity
- cost (Float): Unit cost
- amount (String): Total amount
- date (Date): Item date
- ref_no (String): Reference number

- customer_job (String): Customer job name
- bill (String): Bill number

- class_ (String): Classification
- account (String): Account code
- memo (String): Memo/notes
- buyer (String): Buyer name
- date_added (Date): Date added to system
- export_status (String): Export status
- invoice_id (UUID): Foreign key to invoices
- is_active (Boolean): Active flag (True/False/NULL)

Relationships:
- invoice: Many-to-one with invoices (access invoice fields via "invoice.fieldname")

### Table: suppliers
Fields:
- id (Integer): Primary key
- supplier_name (String): Supplier name

Relationships:
- supplier: One-to-many with invoices
- mpi_mapping: One-to-many with items_mapping
- unmapped_items: One-to-many with unmapped_items

### Table: items_mapping
Fields:

### Table: item_classification
Fields:
- id (Integer): Primary key
- mpi_item (String): MPI item code
- mpi_description (String): MPI description
- class_name (String): Classification name
- account (String): Account code

**IMPORTANT: Amount vs Cost Fields:**
- **amount**: Total line amount (stored as String, use for SUM of totals, revenues, spending)
- **cost**: Unit cost per item (stored as Float, use for unit price calculations)
- When user asks for "total amount", "total spent", "total revenue", use SUM on **amount** field
- When user asks for "average cost per unit", use AVG on **cost** field
- The system automatically handles amount field casting from string to number

**FILTER OPERATORS:**
- eq: Equals (exact match)
- ne: Not equals
- gt: Greater than
- gte: Greater than or equal
- lt: Less than
- lte: Less than or equal
- in: In list of values
- not_in: Not in list of values
- like: SQL LIKE (case-sensitive)
- ilike: Case-insensitive LIKE (PREFERRED for text)
- contains: Contains substring
- starts_with: Starts with
- ends_with: Ends with
- is_null: Is NULL
- is_not_null: Is NOT NULL
- between: Between two values (value must be array of 2 items)

**AGGREGATE FUNCTIONS:**
- count: Count rows
- sum: Sum of values
- avg: Average of values
- min: Minimum value
- max: Maximum value
- count_distinct: Count distinct values

**COMMON QUERY PATTERNS:**

1. **Finding invoices by supplier name:**
   Query invoices table, use relationship field "supplier_fk.supplier_name" with ilike operator
   Example: {"table": "invoices", "filters": [{"field": "supplier_fk.supplier_name", "operator": "ilike", "value": "ABC"}]}

2. **Getting invoice total/sum by supplier:**
   Query invoice_items, aggregate sum on **amount** field (NOT cost), filter by supplier name using "invoice.supplier_fk.supplier_name"

3. **Searching for items:**
   Query invoice_items table, use ilike on description or item fields

4. **Date range queries:**
   Use gte for start date and lte for end date with ISO format (YYYY-MM-DD)

5. **Status filters:**
   For invoices: status = 'PROCESSED' (most common)
   For active items: is_active = true or is_null

6. **Counting/Aggregation:**
   Use aggregates array with appropriate function and group_by

7. **Customer job queries:**
   Query invoice_items, filter on customer_job using ilike
